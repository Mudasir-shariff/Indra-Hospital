# Indira Hospital — Super Speciality Ortho & Urology Center

A modern, responsive, high-performance website for **Indira Hospital — Super Speciality Ortho & Urology Center**, located in Chintamani, Karnataka.

Built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS v4**, and **Lucide Icons**.

## 🌟 Key Features
- **MedixWeb-style Hero Section**: Asymmetrical editorial layout with authentic photography, floating navbar, social proof badges, and frosted glass stat cards.
- **15 Comprehensive Pages**:
  - **Core**: Home (`/`), About Us (`/about`), Facilities & Infrastructure (`/facilities`)
  - **Orthopaedics**: Overview (`/specialities/orthopaedics`), Joint Replacement (`/specialities/joint-replacement`), Trauma & Fracture Care (`/specialities/trauma-fracture`), Arthroscopic Surgery (`/specialities/arthroscopy`), Spine Surgery (`/specialities/spine-surgery`)
  - **Urology**: Overview (`/specialities/urology`), Kidney Stone Laser Clinic (`/specialities/kidney-stones`), Prostate Surgery (`/specialities/prostate-surgery`)
  - **Patient Care & Medical Team**: Our Doctors (`/doctors`), Patient Info & OPD (`/patient-info`), Insurance & Cashless TPA (`/insurance`), Contact & Appointments (`/contact`)
  - **Legal & Compliance**: Privacy Policy (`/privacy`), Terms of Use (`/terms`)
- **Interactive Appointment Booking Modal**: Direct WhatsApp and phone appointment scheduling with department, surgeon, and date preferences.
- **24/7 Casualty & Emergency Integration**: Direct click-to-call casualty hotline (`08154-405616`) and reception line (`+91 79961 14271`).
- **Brand System & Custom Icons**: Incorporates the official Indira Hospital logo, flower emblem, and responsive favicons.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
